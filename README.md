# JS-ASSIGMENTS

A collection of JavaScript exercises, assignments, and practical projects designed to practice core concepts, problem-solving techniques, and modern JavaScript development practices.

---

## 📌 Features & Topics Covered

* **JavaScript Fundamentals:** Variables, data types, operators, and control flow.
* **Functions & Scope:** Arrow functions, closures, callbacks, and scope management.
* **DOM Manipulation:** Interacting with HTML elements, event listeners, and dynamic UI rendering.
* **Asynchronous JS:** Promises, `async/await`, and fetching data from APIs.
